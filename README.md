
# AuraFlow — AI-Powered Daily Routine Redesign
**Capstone 31 | Domain C: Personal Productivity**

AuraFlow is an empirical self-experimentation and schedule optimization platform designed to evaluate generative AI's impact on personal productivity, biological rhythms, and time reclaim.

## Key Features
- **Unity-Inspired Schedules UI:** Horizontal Gantt timeline and habit progress rings.
- **Biological Habit Anchors:** Built-in tracking for Breakfast, Midday Lunch, and 3,500-Step walks.
- **AI Routine Redesign Engine:** Powered by Google Gemini (`gemini-1.5-flash`) for structured JSON scheduling.
- **Task Automation Webhook:** Extracts deadlines and priorities from unstructured messages.
- **Embedded Analytics:** Before-and-after baseline vs. redesigned comparative data charts.
